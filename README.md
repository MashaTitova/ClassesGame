# ClassesGame
## Реализация консольной игры с целью изучения работы с классами, интерфейсами и парадигмой ООП на python.
### Версия Python
- Python 3.13.7
### Как запустить программу:
- Скачать файлы
- Открыть и запустить файл Game.py
### Инструкция
- При запуске игры нужно выбрать аккаунт или создать новый. Аккаунт пользователя сохраняет очки пользователя и статус аккаунта (обычный/премиум).
- Выбрав действие "Управление базой" можно создавать новых юнитов
- При выборе действия "Управление юнитом" можно заставить юнита двигаться, или атаковать объект, а также проверить статус юнита.
- Кроме того, реализованы проверка состояния базы, отмена последнего хода, и сохранение игры.
